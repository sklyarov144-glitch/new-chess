# Royal Chess Quest — MVP для Яндекс Игр

Минимальный HTML5-проект шахматной игры, который можно загрузить на GitHub и дорабатывать через Codex / ChatGPT.

## Что уже есть

- Vanilla HTML/CSS/JS без сборщика и зависимостей.
- Шахматная доска 8x8.
- Легальные ходы основных фигур.
- Шах, мат, пат.
- Рокировка, en passant, превращение пешки в ферзя.
- Простой ИИ на minimax глубины 2.
- Режимы: кампания, задачи, партия против ИИ, ежедневный вызов.
- Монеты, прогресс, косметические темы.
- Таймер удержания 10 минут.
- Заготовки под Яндекс SDK: init, LoadingAPI.ready, GameplayAPI, rewarded video, fullscreen ads, cloud/local save.
- Адаптивный интерфейс для мобильных и десктопа.

## Как запустить локально

Вариант 1 — открыть `index.html` напрямую в браузере.

Вариант 2 — через локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открыть:

```text
http://localhost:8080
```

## Как подготовить архив для Яндекс Игр

В корне архива должен быть `index.html`. Не кладите проект в дополнительную вложенную папку внутри zip.

Пример:

```text
index.html
src/main.js
src/chess.js
src/styles.css
src/yandex.js
assets/
README.md
```

## Важные места для доработки

### Игровой баланс

Файл: `src/main.js`

- `completeChallenge()` — награды, прогресс, реклама после уровней.
- `maybeUnlockSkin()` — условия открытия косметики.
- `startMode()` — логика режимов.

### Шахматные задачи

Файл: `src/chess.js`

Массив `puzzles`:

```js
{
  title: 'Мат в один ход',
  fen: '...',
  solution: 'f1f8',
  reward: 60,
  hint: '...'
}
```

`solution` записывается в формате: `откудаКуда`, например `e2e4`.

### Дизайн

Файл: `src/styles.css`

Основные CSS-переменные:

```css
--bg
--gold
--accent
--light-square
--dark-square
```

### Яндекс SDK

Файл: `src/yandex.js`

Там уже есть методы:

- `init()`
- `gameReady()`
- `gameplayStart()`
- `gameplayStop()`
- `save(data)`
- `load(defaultData)`
- `showRewarded()`
- `showInterstitial()`

Локально SDK не будет найден, поэтому игра работает через fallback на `localStorage`.
